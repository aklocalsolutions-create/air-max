# Air Register (AIR POS look)

Installer downloads only. No source code is kept here.

- **Download:** [AirRegister-AirposLook-Setup.exe](../../releases/latest/download/AirRegister-AirposLook-Setup.exe) (always the latest version)
- Installs next to the regular Air Register as a separate app. Close the regular Air Register before you open this one.
- The app updates itself from this repo's Latest release.
- Windows may show a SmartScreen warning because the installer is not code-signed. Click "More info", then "Run anyway".
